## Ordering

Current code supports a per-tenant ordering requirement. Producers use `tenant_id` as the message key, and the audit consumer checks the expected `tenant_sequence`, raising `SequenceGapError` when a gap is observed. Retryable sequence failures seek back to the same message offset. Relevant references are `gateway/kafka.go:PublishAuditEvent`, `backend/app/services/event_backbone.py:tenant_key`, and `audit_consumer/consumer.py:SequenceGapError`.
